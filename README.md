# AI Business Operations Copilot 🤖

An AI-powered assistant to automate invoices, expenses, tasks, and reports for small businesses.

## Problem
Businesses waste 10+ hours/week on manual data entry, report making, and email follow-ups.

## Solution  
Upload PDF → AI summarizes & categorizes → n8n automation → Auto email reports → Dashboard insights

## Tech Stack
`Python` `OpenAI API` `n8n` `Supabase` `SQL` `Lovable`

## Features
- PDF Upload & AI Data Extraction
- Expense Categorization
- Automated Email Reports  
- Analytics Dashboard
- AI Chat Assistant
